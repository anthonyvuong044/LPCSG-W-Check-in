# LPCSG Food Check-In

A single-page check-in screen for Las Positas College Student Government food collection.

- Students type the 8 digits of their W number (the **W** is already filled in), so a number keypad works.
- A new W number flashes the screen **green**; a W number that already checked in flashes **red** and shows when.
- The **Staff** button (top right) shows the count and the list of W numbers, with search, CSV export and reset.
  It closes by itself after a minute so students don't see it.

## Use it

Download `food-checkin.html` and double-click it to open it in Chrome or Edge. It works offline; the font and logo are built in.
Press F11 for full screen, and make sure Num Lock is on for the keypad.

Check-ins are saved in that browser on that computer. Export the CSV at the end of each event, and Reset before the next one.
